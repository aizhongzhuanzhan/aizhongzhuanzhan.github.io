Sidrune AI是一个面向企业用户与个人开发者的多模型 AI 接入与管理平台。用户通过一个账户和统一 API，可以使用 GPT、Claude、Grok、DeepSeek、GLM、Kimi 等当前开放的模型，不必为每种模型分别管理账户、密钥和账单。

平台提供自营号池及多种非官方 API 线路，用户可以根据预算和使用场景，在价格优先与稳定性优先的线路之间选择。Sidrune AI 兼容常用的 OpenAI、Anthropic 接口，可接入 AI 编程工具、支持自定义接口的客户端，也可通过 SDK 用于应用、脚本和自动化工作流。多线路调度旨在降低单一线路波动的影响，但具体可用性仍以实际线路状态为准。

模型广场公开展示当前模型、线路与价格；工作台提供调用用量和费用记录，方便用户核对支出。平台支持按量余额和订阅套餐，并提供人民币结算、中文指南与支持。模型、价格和可用线路以官网模型广场的实时信息为准。
